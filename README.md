# 迷雾战棋：中国象棋

独立 Tkinter 桌面程序，Python 3.10 或更新版本，使用标准库，无需安装第三方 Python 包。
Windows 双击 `start.bat`，或在本目录运行 `python game.py`。
玩家规则与操作详见主目录的 [游戏说明书.md](游戏说明书.md)。
新增战棋模式详见 [战棋模式说明书.md](战棋模式说明书.md)。开始对局和调试设计均可选择普通/战棋模式与是否启用战争迷雾；关闭迷雾仍保留烟雾与伏兵的遮蔽。
需要保留原来的 `XQPy-0.1` 目录：基础象棋走法通过它的 `Position.legalMove` 判定。
原项目没有被修改。扩展规则不采用标准象棋的将军禁手，胜负按真将被消灭判定。

本项目由GPT协助制作

# 游戏说明书

本文对应当前桌面版。先阅读“通用操作”，再阅读所选模式；完整数值见[详细数值设计说明书.md](详细数值设计说明书.md)。

## 一、通用操作

### 1. 开始游戏

双击主目录的 `start.bat`，或运行 `python game.py`。需要 Python 3.10 及以上和 Tkinter，请保留 `XQPy-0.1` 文件夹。

- **本地双人**：红方先走；结束回合后遮住棋盘，下一位玩家点击“继续游戏”接手。
- **与电脑对战**：玩家执红、电脑执黑。
- **对局设置**：选择普通模式或战棋模式，勾选是否启用战争迷雾。
- **读取游戏**：从 `save` 文件夹读取本游戏的 `.txt` 存档。
- **调试模式及残局设计**：先选模式和迷雾设置，再自由布置局面。

**胜利目标：消灭对方真将。** 假将被消灭不会输；积分只影响战后评价。本游戏不使用标准象棋的“将军禁手”和将死判定。

### 2. 认识棋盘

棋盘有9列、10行，棋子放在交叉点上：

| 项目 | 红方 | 黑方 |
| --- | --- | --- |
| 己方半场 | 第1～5行 | 第6～10行 |
| 九宫／大本营 | d1～f3 | d8～f10 |
| 炮台 | b3、h3 | b8、h8 |
| 瞭望塔 | a4、c4、e4、g4、i4 | a7、c7、e7、g7、i7 |

列从左到右为 a～i，行从下到上为1～10；画面始终红方在下。第5、6行是河界两侧。

### 3. 一回合怎么走

每方每回合有 **3行动点**；红黑各走一次为“一轮”。

| 操作 | 消耗 |
| --- | --- |
| 普通移动或普通攻击 | 3行动点 |
| 普通部署 | 1行动点＋部署点 |
| 勾选行动点减免后部署 | 0行动点，另加部署点 |
| 兵升变 | 2行动点＋部署点 |
| 使用技能 | 通常1行动点，部分为2点或特殊费用 |

每枚棋子每回合最多使用一次技能。不同棋子共用本方行动点。点“结束回合”放弃剩余行动点；行动点为0时也要主动结束回合。

普通走法沿用象棋：车直走、马走日且怕蹩腿、象走田不过河且怕塞眼、士九宫内斜走、将九宫内直走、兵过河后能横走。炮移动不能越子，吃子必须隔一个炮架。装备和技能可以改变这些规则。

### 4. 点哪里、看什么

- **移动／攻击**：先点己方棋子，再点目标。红色小方框提示移动位置及攻击目标。
- **部署部队**：选棋种，再点己方半场的空位；窗口顶部可勾选“行动点减免”。
- **使用技能**：选棋子、选技能，再按提示选择方向或目标；技能下方有说明。
- **兵升变**：选兵，再选择变成车、马、炮、象或士。
- **右键**：取消当前操作；也可点小窗口的“取消”。
- **保存游戏**：保存当前位置、资源、回合及持续状态；返回主菜单前请先保存。

部署、技能、编辑和军需窗口位于游戏窗口左侧；屏幕空间不足时会放在游戏内部左侧。内容较长时可滚动。部署和编辑支持连续操作；技能窗口在成功使用或取消后关闭。

红框和伤害预览只依据己方已知信息，**不代表迷雾中的道路一定安全**。

### 5. 迷雾与冷却

视野通常采用菱形范围：视野1能看见自身及上下左右四格。炮看得较远，未过河的兵也有额外基础视野，车沿直线和斜线观察。

- 开局前三轮有逐渐衰减的额外视野；炮台、瞭望塔提供视野加成。
- 河界第5、6行的棋子强制视野1，技能不能扩大。
- 士在己方九宫内提供该九宫全部视野，并可遮蔽敌方对其相邻四格的观察。
- 烟雾覆盖2×2区域：外面看不进，里面的棋子只看见自己所在格。
- 关闭战争迷雾后，**烟雾和象的伏兵仍能隐藏敌方棋子**。
- 遇到未发现的路径阻挡，移动可能提前停下，行动点仍会消耗。

棋子右下角“待”表示下一己方回合可行动，数字表示还需跳过几个己方回合。“两回合冷却”通常指跳过接下来两个己方回合，第三个恢复。

## 二、普通模式：直接吃子

### 1. 核心玩法

攻击合法且命中时，目标直接被消灭，不计算血量、反击、军需或装备。普通炮吃子会跳到目标格；真将被消灭即判负。

吃子同时获得积分和部署点。部署点可补兵、兵升变、支付部分技能；真将不能复活。

### 2. 部署与升变

只能在己方半场部署兵、炮、车、马、象、士。

- 普通部署花费1行动点及棋种费用。
- 勾选免行动点后，本回合第1次额外付1部署点，第2次付2点，依此增加。
- 第7个在场兵起加价：新部署第7个兵额外2点、第8个额外4点，依此增加。
- 底线、九宫、炮台的新兵下个己方回合可行动；其他位置跳过接下来两个己方回合。
- 兵升变花费2行动点及目标棋种费用；位于敌方半场时再加2部署点。

**普通模式的部署风险：** 已知敌军的邻接或攻击范围不能部署。未知敌军的威胁范围与敌方视野同时覆盖部署格，或格子实际被隐藏棋子占用时，会部署失败：扣费、敌方得分，并禁止本方本回合继续部署。不要把“看不见”当成“安全”。

### 3. 技能速查

| 棋子 | 技能及作用 |
| --- | --- |
| 兵 | **战术调整**：己方半场横移1格；**战术后撤**：后退最多2格。均不能吃子 |
| 炮 | **侦察**：只观察一个方向的整条直线；**烟雾弹**：遮住2×2区域；**轰击**：隔一个炮架原地攻击，不能杀真将或假将 |
| 车 | **出车**：越过一个友军到空位；**冲击**：抵达目标旁并推它1格。均不能吃子 |
| 马 | **快速部署**：连续走两个不吃子的马步；**慌不择路**：无视马腿走一次，可吃子但随后冷却 |
| 象 | **伏兵**：移动或攻击前隐藏；**替死**：付费变成其他棋种并可立即移动；**护驾**：与攻击范围内棋子换位，换敌军时象被吃掉 |
| 士 | **后勤部队**：赚部署点；**伪装**：每局付费制造一次假将；**派遣随军侦察**：永久、可叠加地增加友军视野 |
| 将／假将 | **战地部署**：在空闲友方炮台、瞭望塔批量布兵；**飞将过河**：沿列向敌方底线前进，遇敌将可吃掉 |

炮的轰击第7轮解锁。普通试射落空与轰击落空都会冷却；只有轰击落空允许冷却中使用短侦察。详细费用和时长见数值说明书。

## 三、战棋模式：血量战斗

### 1. 与普通模式的区别

保留行动点、部署、迷雾和大部分技能，但攻击改为扣血：

- 棋子左下角是**当前血量数字**，右上角“轻／重”表示装备。
- 血量越低，攻击越弱；防御代表反击伤害，不是减伤。
- 鼠标悬停在合法攻击目标上，可提前看到预计伤害和反击。
- 目标存活时，马留在原位，车停在目标旁；其他普通攻击通常也留在原位。
- 炮不能对真将、假将造成伤害；真将每个己方回合开始回复1血。

### 2. 军需管理

开局双方各有10军需。之后每回合获得收入，吃子及技能获得部署点时也等额获得军需。

点击“军需管理”，再点己方棋子：

| 选项 | 用途 |
| --- | --- |
| 普通升级 | 己方半场花1军需增加属性；**本方所有棋子每回合合计最多2次，棋子等级无上限** |
| 轻装／重装 | 己方半场花2军需换装，改变基础属性、成长或特殊效果 |
| 回复一半 | 回复最大血量的50%，不超过满血 |
| 回满血 | 补齐缺失血量；钱不够就按实际军需回复 |

以上操作不耗行动点，也不占技能次数。将、假将不能升级或换装，但可以补员。补员可在敌方半场进行，只是效率更低。

每个选项下面列出属性变化和特殊效果；购买后窗口顶部保留本次说明。升级与换装保留已损失的血量，并非直接回满。

### 3. 装备效果速查

| 棋子 | 轻装 | 重装 |
| --- | --- | --- |
| 兵 | 未过河也能四向走，后退不能攻击 | 血量、攻击、防御及成长更高 |
| 炮 | 新增“机动”：2行动点连续移动两次，不能攻击 | 移动力较低；瞄准后炮击能消灭目标 |
| 马 | 视野更远；攻击后自动提示再走相邻1格，点原位放弃 | 属性和成长更高 |
| 车 | 本回合移动增加攻击；新增免费“调整”走1格 | 冲击消耗全部行动点，推撞伤敌；目标后方无空位可强制消灭 |
| 象 | 为周围友军分担一半伤害，在己方九宫内保护整个九宫 | 四向走1格，可以过河 |
| 士 | 换装后每3个己方回合额外赚1军需 | 九宫内四向走；攻击时先承受目标攻击，再造成自身满额防御伤害 |

免费“调整”仍占本回合技能次数。轻马追加移动不耗行动点，不能攻击；普通攻击或攻击技能后均可触发。

### 4. 特殊技能与部署

- 炮的“侦察／轰击”改名为“瞄准／炮击”。瞄准提高炮击倍率，移动或攻击取消瞄准。
- 普通／轻装炮的炮击不能消灭目标；重装炮只有瞄准后炮击可以消灭目标。
- 假将技能1改为“牺牲”：消灭自身，为己方半场友军回血，九宫内和相邻友军获得额外效果。
- 普通模式其余技能继续适用；装备另有说明时以装备为准。
- **部署限制改为**：敌方已有棋子进入己方半场，且部署格在敌方攻击范围内时，提示无法部署；不扣费、不锁定回合。实际占用格也不能部署。

## 四、保存与残局设计

存档位于主目录 `save`，扩展名为 `.txt`，保存模式、迷雾设置、棋盘、双方资源、升级次数、装备、技能和持续状态。读档不会自动转换模式；本游戏存档不是 XQPy 原棋谱。

调试模式可切换上帝／红方／黑方视角，连续放置、替换或删除棋子；“玩家数据”可修改积分、部署点、军需、轮数、当前玩家和行动点。编辑窗口右键取消。

测试残局前，双方必须各有一个真将。建议先保存设计，再选择本地双人或电脑对战测试。

贴图放入 `textures`，在 `config.json` 的 `textures` 中配置；无图时使用文字棋子。详见 `textures/README.md`。


## 扩展接口

`config.json` 的 `piece_stats` 已预留 attack/hp，存档棋子带 attack/hp/max_hp。
普通模式由 instant_kill 控制，默认直接吃子。战棋模式独立使用完整血量、装备、反击和支援伤害规则，不受普通模式的 instant_kill 开关影响。

战棋棋子左下角显示当前血量数字，右上角显示轻重装备。选择棋子后，红色小方框标出可移动交点和攻击目标；范围仅依据当前已知棋盘，迷雾中的阻挡仍可能使行动受阻。轻马攻击后自动提示追加移动，点选原位可放弃。普通升级为每方每回合合计两次，等级无上限；军需窗口显示具体属性变化和装备效果。
贴图配置详见 `textures/README.md`。缺失图片自动回退为文字棋子。
电脑策略独立于界面，可用 `python -m computer.opponent save/某存档.txt` 输出下一步 JSON 指令。
当前电脑为视野受限的启发式基础对手，支持移动、部分技能（含轰击）和部署，遵守3行动点及部署锁定，尚非适配全部技能的深度搜索引擎。
战棋电脑还会按可见伤害评估攻击、使用军需补员和普通升级，并进行轻马追加移动；尚未为所有轻重装技能设计完整战术搜索。
