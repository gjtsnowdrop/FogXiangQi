# 迷雾战棋：中国象棋

独立 Tkinter 桌面程序，Python 3.10 或更新版本，使用标准库，无需安装第三方 Python 包。
Windows 双击 `start.bat`，或在本目录运行 `python game.py`。
玩家规则与操作详见主目录的 [游戏说明书.md](游戏说明书.md)。
新增战棋模式详见 [战棋模式说明书.md](战棋模式说明书.md)。开始对局和调试设计均可选择普通/战棋模式与是否启用战争迷雾；关闭迷雾仍保留烟雾与伏兵的遮蔽。
需要保留原来的 `XQPy-0.1` 目录：基础象棋走法通过它的 `Position.legalMove` 判定。
原项目没有被修改。扩展规则不采用标准象棋的将军禁手，胜负按真将被消灭判定。

## 目录

```text
game.py                 桌面界面与入口
engine.py               棋盘、迷雾、技能、计分和存档
tactics.py              战棋数值、轻重装备、反击、军需和伤害预览
config.json             分值、攻防血量和贴图配置
textures/               可替换棋子图片
save/                   txt 存档（包含棋谱行动记录）
computer/opponent.py    独立电脑对手策略
tests/                  规则回归测试
XQPy-0.1/               原始开源象棋程序
```

## 操作

开始游戏可选择本地双人或与电脑对战。红方先行。
选择己方棋子，再点击目标格移动；炮隔一个炮架跳到目标格吃子，也可以向迷雾格试射，空炮不移动并冷却。
部署、使用技能、编辑棋盘的选择窗口固定在游戏左侧，主窗口移动时跟随。左侧空间不足时窗口靠游戏内左侧，棋盘预留空间，保证目标格不被遮挡。
部署窗口选择棋种后保持打开，支持连续部署和切换棋种。普通部署消耗1行动点；勾选顶部“行动点减免”后改为免行动点，但本回合第1、2、3次减免分别额外花费1、2、3部署点，窗口实时更新各棋种费用。部署失败会锁定本回合后续布兵。
技能窗口显示技能说明与行动点消耗，选择技能和目标期间保持打开，成功使用后关闭。快速部署要依次选择两步落点。
右键可在棋盘、主窗口或选择窗口取消当前行动；取消按钮和窗口关闭按钮也会退出相应模式。编辑窗口在连续放置、替换或删除棋子后仍保持打开。
替死先选择升变棋种，再选择立即移动的目标；点击原位表示放弃立即移动。
兵升变有独立按钮。每回合行动点最多3，普通移动消耗3；原有2点技能、兵升变仍消耗2，其余技能消耗1。结束回合会放弃剩余行动点。
本地双人交接遮住整个界面，由下一位玩家点击继续后才显示其视野。
存档为 UTF-8 的 JSON 文本，扩展名 txt，保存模式、迷雾开关、棋子属性、装备等级、军需、技能、冷却、视野、部署、交接、随机序列和行动记录。新版格式为4，仍可读取格式1、2、3旧存档，旧档默认为普通模式并启用迷雾；旧的侦察加成转为1层，保留旧存档当前行动点，之后新回合恢复3点。
调试模式支持连续放置/替换/删除棋子、编辑双方分数/部署点/轮数/行动方/行动点、三种视野和测试残局。
测试残局前请先保存调试存档，测试时从当前部署继续正式对局。

## 规则解释与边界

以下为普通模式规则。战棋模式的属性、伤害、军需和不扣费部署限制由 `tactics.py` 实现，见独立说明书；普通模式保持秒杀及原部署失败惩罚。

- 棋盘实际为9列10行，坐标为 a–i 列、1–10 行。红方底线为1，黑方底线为10；界面固定红下黑上。
- 一轮为红黑各一个回合，初始第1轮。第1–4轮全域加成依次为3、2、1、0；双方进入自己的回合时领取当轮部署收入。
- 用户已确认一般视野为菱形：曼哈顿距离不超过半径。车例外，基础视野为上下左右各3格、四个斜向各1格；开局和地形加成扩展对应射线的长度。河界为第5、6行，强制菱形半径1，无法受技能增幅。
- 炮台和瞭望塔为开局位置，永久保留；不随初始棋子移动。任一方站上这类地形都享受视野加成。
- 士遮蔽为被动效果，始终遮蔽敌方视野中的相邻四格，能够覆盖九宫格额外视野；己方仍能看到自己的棋子。
- 侦察持续4个己方回合，包含施放回合，仅保留所选方向整条直线和自身格的视野；普通移动、被推动或攻击会取消。河界不能使用侦察扩大视野。从施放方第2个回合开始，敌方只能在自身已拥有的视野格看到虚线侦察线，线条不改变其视野，也不会额外揭露棋子。
- 烟雾覆盖完整2×2区域。区域外的棋子无法看见区域内部；区域内的棋子仅贡献自身所在格，不贡献相邻格。任何棋子进入仍有效的烟雾都会受影响，离开恢复视野，再次进入会再次受影响。队伍视野仍由己方棋子合并，因此己方烟雾内棋子的自身格可见，其他内部格无法被外部视野揭开；开局、地形、九宫格、侦察和随军侦察均不能绕过遮蔽。施放方持续本回合及下一己方回合，对方持续接下来的两个回合，重叠烟雾直到对应覆盖全部失效才解除。
- 通常进入两回合冷却：接下来的两个己方回合不能移动或用技能，第三个己方回合恢复。轰击落空冷却另有仅允许一回合侦察的例外。底线/九宫格/炮台部署在下一己方回合可用；其他部署包括瞭望塔跳过两个己方回合。冷却不阻止被动视野。
- 已知阻挡拒绝非法走法；未知直线路径阻挡让棋子停在阻挡前，不能吃阻挡棋子并消耗移动行动点。未知马腿/象眼阻挡时停在原位。
- 普通炮移动、吃子和象棋一致，吃子时跳过恰好一个炮架并落在目标格。向炮架后的空格试射时不移动，冷却两个己方回合。
- 炮技能3轰击开局前6轮不能使用，第7轮解锁；此限制只约束轰击，炮的移动、普通吃子和其他技能仍按正常规则。轰击需要一个炮架，沿直线原地攻击；消灭非兵棋子返还敌方1部署点，消灭兵不返还，对真将与假将不能使用。轰击空格会进入两个己方回合的特殊冷却，期间不能移动、吃子或使用其他技能，仅可使用持续1个己方回合的侦察。每棋子每回合一次技能的限制仍然生效，因此落空当回合不能立即再侦察。冷却结束后侦察恢复4回合。
- 已知敌方邻接及攻击范围禁止普通部署，不扣点。隐藏威胁只有在部署格同时处于敌方视野、邻接或攻击范围时才导致部署失败；隐藏占用格不能叠放棋子，也会失败。失败扣除部署点、敌方获得对应积分，并锁定本回合后续部署（包括伪装和战地部署），下一己方回合解锁。
- 普通部署耗1行动点；额外付部署点可免行动点，附加费按每方本回合的减免次数递增，下一己方回合重置。勾选、取消和无效选格不计次数；实际部署尝试（含迷雾中失败）才计数。失败时也支付减免附加费，敌方积分按棋子分值计算，不包含减免手续费。伪装和战地部署仍使用各自技能的行动点规则。
- 普通部署兵时，按己方全部在场兵数额外收费，含过河及冷却中的兵。新兵为第7、8、9个时分别额外花费2、4、6部署点，与行动点减免费叠加。兵被吃掉或升变后数量减少，下次部署费用随之降低。该附加费不增加吃子分值，也不改变战地部署固定2部署点的技能费用。
- 用户已确认冲击：车抵达直线目标旁，将目标沿该方向推一格；后方受阻只抵达旁边。出车可越过恰好一个友方棋子，不能吃子。
- 快速部署两步作为一个原子操作，第一步不向界面或电脑公开视野。任何一步受阻则停在已完成位置并冷却。
- 后勤部队收益为 `1 + floor((轮数-1)/3)`，即第1–3轮1点、第4–6轮2点，依此类推。
- 士技能3派遣随军侦察，消耗1行动点，目标必须是位于己方棋盘的友方棋子。每次永久+1视野，可叠加；同一目标第1次无额外部署费，第2、3、4次分别额外花费1、2、3部署点，各目标独立计数。随目标过河仍有效；只对新增视野进行敌军遮挡检查，第一排敌军可见，后方增量格不可见。普通视野不受这项技能遮挡影响，河界视野仍强制为1。
- 伪装每方每局一次，遵循己方部署和威胁检查；只有拥有方和调试上帝视角看见伪字和行动冷却标记，敌方不会看到假将右下角的“待”字或冷却数字。敌方电脑也无法获知假将身份。
- 战地部署是独立全局布兵技能，固定2行动点与2部署点，在所有空闲友方炮台/瞭望塔布兵，按技能描述直接部署。
- 飞将向敌方底线直线移动，遇到非将棋子停在其前方；遇到敌方真将杀将胜利，遇到假将仅正常吃假将。在九宫格外不能普通移动，但冷却结束且有行动点时仍可使用技能。
- 象替死可升级为车、马、炮、象、士，并立即进行一次合法不吃子的移动；兵升变允许这些棋种，敌方棋盘额外消耗2部署点。
- 象技能3护驾消耗1行动点，与象攻击范围内的一枚棋子交换位置，受两格斜向、象眼和不过河限制。友方棋子交换后双方保留；与敌方交换后象被敌方吃掉，敌方留在象原位并获得象的积分和部署点。交换作为一个操作执行，不产生重叠格；移动双方会解除伏兵、取消侦察，并按离开烟雾区域的规则解除烟雾影响。
- 未提供全局技能清单，当前只实现上述棋子技能；未来可通过规则引擎增加全局技能。
- 用户已确认评价按高倍率优先；“损失惨重”采用己方积分小于敌方一半。相等积分归为胶着，失败评价按描述处理。

## 扩展接口

`config.json` 的 `piece_stats` 已预留 attack/hp，存档棋子带 attack/hp/max_hp。
普通模式由 instant_kill 控制，默认直接吃子。战棋模式独立使用完整血量、装备、反击和支援伤害规则，不受普通模式的 instant_kill 开关影响。

战棋棋子左下角显示当前血量数字，右上角显示轻重装备。选择棋子后，红色小方框标出可移动交点和攻击目标；范围仅依据当前已知棋盘，迷雾中的阻挡仍可能使行动受阻。轻马攻击后自动提示追加移动，点选原位可放弃。普通升级为每方每回合合计两次，等级无上限；军需窗口显示具体属性变化和装备效果。
贴图配置详见 `textures/README.md`。缺失图片自动回退为文字棋子。
电脑策略独立于界面，可用 `python -m computer.opponent save/某存档.txt` 输出下一步 JSON 指令。
当前电脑为视野受限的启发式基础对手，支持移动、部分技能（含轰击）和部署，遵守3行动点及部署锁定，尚非适配全部技能的深度搜索引擎。
战棋电脑还会按可见伤害评估攻击、使用军需补员和普通升级，并进行轻马追加移动；尚未为所有轻重装技能设计完整战术搜索。
